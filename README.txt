SHIFA MEDICAL CENTRE - TOKEN SYSTEM

PEHLI BAAR (sirf ek dafa):
1. Python install karein (python.org). "Add Python to PATH" tick karein.
2. SETUP.bat par double click karein. Desktop par icon ban jayega.
3. App kholein, admin se login karein, Settings me "Thermal printer" select karein aur Test print karein.

PRINTING:
- TOKEN  -> thermal printer (Settings me chuna hua), seedha bina dialog ke.
- CASH MEMO (centre bill, doctor fee bill, store bill) -> normal printer, A4 page ke upar aadhe hisse me.
- Doctor patient sheet / Patient record -> A4 page.
Normal printer ko Windows me default printer rakhein.
